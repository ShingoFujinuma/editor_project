# 使い方

まずは[ここ](https://shingofujinuma.github.io/editor_project/)にアクセス<br>
ここからエディターにアクセスできるよ<br>
スマホからの編集は想定も動作確認もしてないので、なるべくPCからの編集をお願いします

1. Ctrl+Oまたは右のツールバーの下のほうにある音源を開くボタンを押すとファイル選択画面が出てくるので、音源ファイルを選択<br>
ファイル形式はmp3でもwavでもおっけー
2. 新規で譜面を作る場合は、ツールバーの真ん中あたりにある初期設定にBPMと拍子を入れて反映<br>
保存してある譜面を読み込む場合は、もう一度Ctrl+Oを押すかツールバーの下のほうにある譜面を開くボタンを押してjsonファイルを選択
3. レーンのグリッドの近くを左クリックでノーツ配置、右クリックで削除

あとはまあなんかエディターに書いてある通りです 隅々までよく見てもわからなかった場合はAsに聞いてくれ

あとなんかバグとか改善点あればAsに言ってください<br>
余裕があれば直します
